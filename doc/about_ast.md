这里定义该使用 AST 做什么。

# 为什么需要 AST

在 JS 层次想要**定位值产生的位置**，需要将**涉及产生值的语句**使用一个方法包裹（比如取名为 `record`），这样就能在 `record` 方法中记录这个值的产生，以及所处的堆栈。

我们不关心这个值参与了什么计算，只关心它最先在哪里出现。

```js
// 值的产生可能是一个复杂的表达式
let a = md5('content');

// 处理成这样，在 record() 中记录值的产生以及堆栈
let a = record(md5('content'));

// 关于 record() 的实现可以简单理解为下面这样
function record(value) {
    const stack = get_stack();   // 生成堆栈
    database.add(value, stack);  // 记录值
    return value;
}

// 后续可以查看某个的值生成的位置
database.find(value)
```



所以需要找到产生值的位置，然后增加代码。这就需要使用 AST（抽象语法树,`Abstract Syntax Tree`)，它是代码的一种抽象表达，操作它来修改代码更方便 —— 总不能让我使用正则去匹配。

# 使用 AST 处理的情况

下面将说明使用 AST 处理哪些情况、忽略哪些情况，从而插入 `record()`。



## 变量声明

因为**需要记录值【最先出现】的地方**，所以需要处理它。

**只关注字面量值**，当前只处理字符串（`string`），不会处理数组、对象的初始化等。

```js
// 如果初始值为空则不会被记录
let a;

// 1. 普通声明
let a = x;
// === 处理成 ===
let a = record(x);


// 2. 连等式声明
let a = b = c = x;
// === 处理成 ===
let a = b = c = record(x);
// 只处理最右侧的那个值
// 在具体实现上，此种情况交给【赋值表达式】处理


// 不会 record 数组本身，专注于字面量
// 当然，也许数组中的元素也是字面量，那也忽略
let a = [1, 2, 3];
```



## 赋值表达式

通常会通过计算得到一个值，然后赋值给变量，这里**可能就是值【最先出现】的地方**。

```js
// 基本就是和上面处理变量声明的情况相同
// 1. 普通赋值
a = x;
// === 处理成 ===
a = record(x);

// 2. 连等式赋值
a = b = c = x;
// === 处理成 ===
a = b = c = record(x);
```



## 对象的属性

重点的是属性的初始值，因为这可能**是值【最先出现】的地方**，而不是对象本身以及如何访问其对象。

```js
// 当定义变量、或者赋值，且值是一个【对象】时，
// 不会处理该对象本身，但会处理其中的属性
// 如下，不会有 record({ ... }) 来包裹整个对象自身
// 因为对象是由属性组成，直接 record 属性就好了
let a = {
    x: 1,
    y: {
        z: 2
    },
};
// === 处理成 ===
let a = {
    x: record(1),
    y: {
        z: record(2)
    },
};

// 同时，以下访问属性的情况就不需要处理了
a.x;
```



## 函数

函数的重点在于**传递的参数和返回值**。

```js
// 函数的返回值被赋值或用于初始化
// 这其实属于上文的【初始化、赋值表达式】等情况，由它们处理
let a = func(x);
// === 处理成 ===
let a = record(func(x));
```



对于参数，有两种方案，最终选择第一种！

```js
func(1, 2);

// === 处理成 === 
// 第一种处理方式，在调用之前处理参数
func(record(1), record(2));


// 第二种处理方式，在函数体内部的顶部处理
function func(a, b) {
    record(a); // 插入 record 方法
    record(b);
    ... // 函数体原本的内容
}

// 经过实践，应该选择第 1 种方式，因为可能在当前作用域中没有该函数呢
// 更何况还有调用内置方法的情况，所以应该 record 参数
// 比如下面这种只有方案 1 才能 record 到
"x".replace('x', 'hello')
```



## 总结

因为**重点在于值【最先出现】的地方**，要么是初始化时、要么就是函数的参数、返回值。

可能还会有**高级 JS 语法**的情况，比如 `class` 等，嘛，到时候再说。
